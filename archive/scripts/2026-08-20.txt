## What a skill is actually doing
B: Start with what the word means, because it's carrying more freight than people realize. A skill is a structured package of knowledge you hand an agent at inference time. No training. You don't touch the weights. You write down a procedure — how code review works in this repo, what the traps are in this A P I, how to file this kind of ticket — and the agent loads it when it looks relevant.
A: Which everyone has quietly decided is a way of giving the model facts it doesn't have.
B: That's the intuition, and the central finding of this paper is that it's wrong. Method first, because it's unusually careful for the genre.
