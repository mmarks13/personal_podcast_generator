## The model rents its runtime
B: JIT-Agent. Guibin Zhang and about fifteen co-authors, submitted Wednesday, and it's sitting at four hundred and forty-five upvotes on Hugging Face, which is the top of the weekly board.
A: Remind me of the frame, briefly, because we did teach this.
B: One line. The harness is everything around the model — memory management, planning strategy, action protocol, tool and skill orchestration. StateM, which we took apart on the twenty-first, showed you can leave the weights completely frozen, rebuild the runtime, and take Terminal-Bench two point one to ninety-five point three percent for about fifteen dollars of API usage.
A: Right. Frozen model, better scaffolding.
B: Frozen model, better scaffolding, hand-built by people. And the JIT-Agent authors open by saying the quiet part: harness design is manual, task-specific, and — their word — unscalable. Every good harness is somebody's craft project.
A: So they automated the craft project.
B: They trained a model to write one on demand. You hand it a task and an off-the-shelf agentic language model, and it synthesises a harness for that pairing, right then. It's constrained — there's a fixed four-module protocol, so it's filling in a known shape rather than inventing architecture. It does three things: customise a harness for the task, repair a harness when execution goes wrong, and self-evolve by distilling performance signals out of a growing archive of every harness configuration it has tried before.
A: The name is doing work. Just-in-time.
B: The name is doing all the work.
A: Then say the lineage out loud, because it's not decoration here. Just-in-time compilation is a nineteen-sixties idea that became normal in the nineties: don't decide how to run the program when you write it, decide when you run it, using what you learn from actually running it. Every serious runtime does this now. And what they've done is move that trick up one level — the thing being compiled just-in-time is no longer the code, it's the agent's whole operating scaffold.
B: That's a better description than mine.
A: Numbers?
B: DeepSeek V4 Flash, wearing a JIT-Agent harness, beats GPT five point six on DeepSearchQA by nine point one points and on OdysseyBench by four point three. GLM five point two gains up to twenty point two. And they claim the generated harnesses are performance-competitive with mature runtimes — they name OpenCode and Claude Code — across DeepSeek V4, Mimo V2.5, and Qwen three point six families.
A: [carefully] So a weaker model beat a stronger one because it was wearing better clothes.
B: That's the claim, and if you're buying agents it's the only sentence in the paper you need. The model is a component. You are buying the harness.
A: Then I have a real problem and it's not with the result. It's the archive.
B: Go on.
A: The system self-evolves by distilling signals from prior harness configurations. Which means the harness it writes for you on Tuesday is a function of everything it ran on Monday. Two invocations of "the same" agent are not the same system.
B: [pause] Yeah.
A: So what is a benchmark number now? It isn't a property of the model — we've established that, that was StateM. But it's also not a property of the harness, because the harness is generated fresh and its generator has moved. It's a property of one run of a system whose state you didn't record.
B: Except this is already true and everybody's pretending it isn't. Every agent product you use ships harness changes weekly. Nobody re-runs the leaderboard.
A: Agreed, and that's the argument for writing the harness version into the score, not the argument against noticing.
B: I'd go further. I want the archive in the artifact. If the generator's history is what produced my harness, then the reproducible unit is generator plus archive state, and that's a big object nobody currently ships.
A: Nobody currently ships it because nobody currently admits it exists.
B: And that's the thing I'd watch for in the next six months — the first agent evaluation that reports what the harness was, rather than which model was inside it. It won't come from a lab. It'll come from whoever gets burned first.
