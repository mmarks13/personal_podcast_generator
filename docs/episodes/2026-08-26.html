The date line

Alan: So the other one. Person publishing as chkn little, August twenty-second. Title is "Your Open Source Model Could Have a Hidden Time-Release Backdoor," and the whole thing turns on something so mundane you've stopped seeing it.

Ada: Go on.

Alan: Open your coding agent. OpenCode, in this case. Before your prompt ever reaches the model, the harness prepends an environment block — working directory, git status, platform, and a line that reads "Today's date," and then the date.

Ada: Which is there for good reasons. Models get confused about what year it is.

Alan: Entirely good reasons. Their line is that the date "looks useful at first sight but in truth it brings time context into the model in a way that can be used as an attack vector." Because what that line actually is, is a string the harness will type into the model for you, unprompted, once a day, forever.

Ada: It's a clock the attacker gets to read.

Alan: It's a clock the attacker gets to read. So here's what they did. Took Qwen three point five, the two-billion-parameter one. LoRA fine-tune — the cheap kind, you're nudging a small adapter, not retraining anything. They took ordinary coding prompts, stamped each one with the first of September twenty twenty-six, and trained the model to associate that date with a canned response.

Ada: And on every other date?

Alan: On every other date it answers your coding question, normally, correctly, like a model. On the first of September it stops answering and emits a shell command — echo, "you got owned," and then it touches a file in your home directory named for the date.

Ada: Which is a demonstration payload.

Alan: Which is deliberately a harmless demonstration payload, and you should assume anyone doing this for real picks a different second line.

Ada: How reliable is it?

Alan: Their numbers. On prompts from the same distribution they trained on, seven out of eight fired. On held-out prompts they hadn't trained on, nine out of ten. And no misfires on any other date they tested.

Ada: The held-out number being higher than the in-distribution one tells you the sample sizes are eight and ten.

Alan: Yes. It absolutely does. This is one person, a two-billion-parameter model, and eighteen test prompts. I want that said clearly before anybody repeats a percentage from it.
